# Perfekt context audit

Extends the existing /perfekt/ page, not a second trainer. Six contextual checks: intransitive/transitive fahren, -ieren, separable, inseparable and weak participles. Context panel is the default. Existing context-free auxiliary quiz is reduced to six common less ambiguous core verbs; variant-prone position/movement verbs no longer get forced choices. Legacy rule summaries softened and tied to context. Table entries describe listed core uses, not all usages. No universal participle generator.

Checked source pages 2026-11-16:
- https://deutschegrammatik20.de/verbformen/die-konjugation-perfekt/bildung-perfekt-haben-sein-2/
- https://deutsch.lingolia.com/de/grammatik/verben/partizipien
