# Main device progress validation
Validate numbers, counters/maps, seen records, SRS boxes/dates and score rows before rendering. Missing legacy fields get fresh independent defaults, valid history remains. Malformed fields are excluded from the displayed fallback, but the original serialized record is retained and all progress writes refuse to overwrite it. Storage failures emit a visible site-wide warning instead of throwing through click handlers. No automatic reset/deletion/migration.
