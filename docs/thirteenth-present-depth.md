# Present-form depth

Expanded the existing present-only focus from six to twelve verbs (72 person/form cells). Six new verbs: nehmen, geben, fahren, arbeiten, wissen, sehen. All six forms of each were checked against the linked Netzverb present-indicative overview on 2026-11-16. Sources are kept on each data row and linked from the active exercise.

Added specific stem/ending contrast notes and a next-person control that clears the previous input/result. The new verbs are deliberately NOT added to the eleven-tense/mood lab: checking their present forms is not evidence for other tenses. Full standard forms are accepted, not colloquial dropped-e variants. Unicode NFC normalization preserves composed umlauts. This is free typing practice without saved scores or points; this limit is now explicit on screen.
