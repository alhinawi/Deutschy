# Practical text glossary

24 new nouns, none duplicating the 662 photo-dictionary headwords. Four groups
cover paperwork, work, training and university. The photo dictionary is unchanged;
this is a clearly separate text-first resource, not 24 new photo cards.

Live German Wiktionary revision API checks match all selected articles and
plurals. Exact observed page URLs and definition excerpts are retained in
practical-glossary-audit.json. Gehalt was separately checked against its salary
sense: das Gehalt / die Gehälter, not der Gehalt / die Gehalte (content).
Weiterbildung was rejected from this batch because the checked source did not
list the proposed plural; Fortbildung was verified and used instead.

Examples and Egyptian glosses are original. They do not describe real vacancies,
awards, appointment times or current procedures. No legal/immigration advice.
No images added to abstract concepts. No fabricated saved progress or scores.
Recall reveal/hide, all four groups, salary search, empty search, mobile overflow
and WCAG A/AA axe checked. Native-speaker proofreading remains unverified.
