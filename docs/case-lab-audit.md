# Case contrast extension

Existing preposition reference, diagrams, randomized trainer and case tables
were inspected before adding this focused extension. Twelve original paired
choices cover location/destination, verb-governed case and fixed/verb-bound
prepositions. In particular, running within a park still takes local dative;
a destination with zu still takes dative. Not a motion-equals-accusative rule.
