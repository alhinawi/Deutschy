# Goal-based study start guide

Five goals: basics, speaking, work/study, writing, review. User-selected practice
grouping includes unsure. There is no inferred level, placement result, score,
completion estimate or account write. Suggested time split totals 10 or 20
minutes and is labeled attention planning, not a required completion duration.
The timed-practice step explicitly plans a future session rather than promising
a full 10-minute test fits in a three-minute slot.

C1/C2 choices route to existing advanced writing and conversation, not the A1-B2
cards/frames. Tools that do not accept a level link clearly need selection inside.
Empty real review is explained rather than filled with sample progress.

All 70 goal/group/time combinations unit and browser tested. Five goal axe
states pass, no mobile horizontal overflow. Home and sidebar expose the guide.
Unit/typecheck/build/export pass; mobile screenshot inspected.
